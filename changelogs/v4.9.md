## 🎉 Fitur Baru v4.9

### 1. **Manajemen Service Systemd (Test-Dulu-Baru-Restart)**

Semua service VPN kini dikelola via 2 helper terpusat di `lib/common.sh`:

| Helper | Tugas |
|---|---|
| `svc_restart_tested <unit> <test...>` | Validasi konfigurasi dulu, **batalkan restart bila tes gagal** (service yang berjalan tidak tersentuh), lalu `daemon-reload` + `enable` + `restart` + cek `is-active` + tampilkan `journalctl` bila gagal |
| `svc_restart <unit>` | Ringan untuk service tanpa binary config-test (ssserver, ssh-ws, stunnel): `daemon-reload` + `enable` + `restart` + status |

Penerapan per service:

- **Xray**: `xray run -test -config` **wajib lolos sebelum restart** — saat setup server, tambah user (`xray_create_user`), dan hapus user (`xray_remove_user`). Config rusak tidak pernah menyentuh service yang berjalan. Unit `xray.service` label v4.9 + auto-start on boot (`systemctl enable`).
- **OpenSSH (sshd/ssh)**: `sshd -t` wajib lolos sebelum restart hardening (`ssh_harden_config`).
- **Dropbear / Stunnel / ssh-ws / Shadowsocks / OpenVPN / WireGuard / vpn-limits / telegram-bot / web-dashboard**: migrasi ke `svc_restart` — `enable` eksplisit sehingga **otomatis berjalan saat VPS di-reboot**.
- **Menu 14 (Restart all)**: sshd + xray divalidasi dulu via `svc_restart_tested`; WireGuard memakai `syncconf` tanpa putus koneksi (fallback `svc_restart`); sisanya via helper.
- **status.sh**: setiap service kini menampilkan status `enabled:` (auto-start on boot) + hasil `xray run -test` (OK/FAIL).

### 2. **Output & Manajemen Akun (Ringkasan Tersimpan + QR)**

Setiap pembuatan akun kini **mencetak DAN menyimpan teks yang SAMA**:

| Fungsi | Tugas |
|---|---|
| `summary_init()` | Siapkan `/etc/vpn-script/` (mode 700) + file `client-config.txt` (mode 600, ada peringatan secrets) |
| `summary_block "TITLE"` | Tambahkan satu blok berjudul + timestamp ke file ringkasan |
| `show_and_save "TITLE"` | Cetak ke terminal + simpan ke file sekaligus |

Cakupan per protokol:

- **WireGuard** (`wg_create_client`): blok berisi endpoint, file `.conf`, PNG QR, DNS, alamat IP + **isi penuh `.conf`** + render QR ANSI via `qrencode` ke terminal.
- **Xray** (`xray_print_links`, default `SAVE=1`): 13 link lengkap + UUID + SNI tersimpan otomatis; `show-account.sh` memakai mode display-only (`SAVE=0`) agar tidak duplikat.
- **SSH** (`ssh_create_user`): host, 4 port (SSH/Dropbear/TLS/WS), username, password, masa berlaku, contoh perintah `ssh -p`.
- **OpenVPN** (`ovpn_create_client`): path profil `.ovpn` + server `IP:port/proto`.
- **Shadowsocks** (`ss_setup_server`): host, port TCP+UDP, method, password, URI `ss://`.

Script pendamping baru **`show-account.sh`** (menu **25**):

```bash
sudo ./show-account.sh                  # tampilkan seluruh ringkasan tersimpan
sudo ./show-account.sh <username>       # tampilkan ulang 1 user (WG .conf / Xray links / SSH / OVPN / SS)
sudo ./show-account.sh <username> --qr  # + render ulang QR WireGuard
```

File: `/etc/vpn-script/client-config.txt` (mode 600) — bisa dibaca kapan saja via `cat`, status ukuran/jumlah baris tampil di `status.sh` bagian 8, dan dihapus bersih oleh `uninstall.sh`.

### 3. **Bug Fix Kritis (Ditemukan Saat Audit v4.9)**

- **`done` nyasar di `xray_setup_server`** (sisa loop batch v4.6) — syntax error yang menggagalkan seluruh setup Xray. Dihapus.
- **Path absolut salah** `source "/lib/ssl.sh"` di `status.sh` + `uninstall.sh` — modul SSL tidak pernah termuat. Diperbaiki ke `source "$SCRIPT_DIR/lib/ssl.sh"`.
- **Path OpenVPN salah** di `show-account.sh` (`$OVPN_CLIENTS_DIR/$user/$user.ovpn` vs real `$OVPN_CLIENTS_DIR/$user.ovpn`) — diperbaiki + tambah blok Shadowsocks yang belum ada.

## 🔧 Perubahan Teknis

### File yang Dimodifikasi

1. **`lib/common.sh`** — 5 fungsi baru (`svc_restart_tested`, `svc_restart`, `summary_init`, `summary_block`, `show_and_save`) + konstanta `VPN_SUMMARY_DIR/FILE`
2. **`lib/xray.sh`** — validasi `run -test` fatal sebelum restart (setup/create/remove user), `xray_print_links` parameter `SAVE`, label unit v4.9
3. **`lib/wireguard.sh`** — `wg_enable_and_start` + `wg_reload_config` via helper, hook `show_and_save` + QR terminal di `wg_create_client`
4. **`lib/ssh.sh`** — `ssh_harden_config` via `svc_restart_tested sshd -t`, dropbear/stunnel/ssh-ws via `svc_restart`, hook `show_and_save` di `ssh_create_user`
5. **`lib/openvpn.sh`** — enable via `svc_restart`, hook ringkasan di `ovpn_create_client`
6. **`lib/shadowsocks.sh`** — restart via `svc_restart`, hook `show_and_save` (duplikasi URI dihapus — blok cetak manual diganti helper)
7. **`lib/limits.sh`** — monitor via `svc_restart`
8. **`show-account.sh`** (baru) — 5 protokol + `--qr`, dipakai menu 25
9. **`menu.sh`** — menu 14 test-driven restart, menu 25 baru, footer v4.9
10. **`status.sh`** — kolom `enabled:` semua service + hasil `xray run -test` + seksi 8 ringkasan tersimpan
11. **`uninstall.sh`** — hapus `/etc/vpn-script/`
12. **`install.sh`** — label v4.9 + baris quick-command `show-account.sh`
13. **`setup-telegram-bot.sh` / `setup-web-dashboard.sh`** — enable via `svc_restart`

### Kompatibilitas

- Tanpa dependensi baru (`qrencode` sudah ada sejak awal; `sshd -t`/`xray run -test` bawaan binary masing-masing)
- Semua `enable` bersifat idempotent (`>/dev/null 2>&1 || true` di dalam helper)
- `show_and_save` tidak pernah menggagalkan pembuatan akun (append file best-effort setelah akun sukses dibuat)
- File summary mode 600 — aman untuk UUID/password

## 📦 Cara Verifikasi di VPS

```bash
# 1. Config rusak tidak boleh merestart service yang berjalan
sudo python3 -c "import json;c=json.load(open('/etc/xray/config.json'));c['inbounds']=None;json.dump(c,open('/etc/xray/config.json','w'))"
sudo ./add-xray-user.sh testuser   # harus GAGAL di config-test, xray tetap jalan
sudo systemctl is-active xray      # harus active

# 2. Reboot persistence
sudo systemctl is-enabled xray wg-quick@wg0 ssh-ws stunnel4 shadowsocks-rust  # semua enabled
sudo reboot && sudo systemctl is-active xray wg-quick@wg0  # active setelah boot

# 3. Ringkasan tersimpan
sudo ./add-client.sh phone-qr
cat /etc/vpn-script/client-config.txt   # blok WG + isi .conf ada
sudo ./show-account.sh phone-qr --qr    # .conf + QR tampil ulang
sudo ./status.sh                        # seksi 8 tampil ukuran file
```
