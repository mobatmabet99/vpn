## 🎉 Fitur Baru v4.7

### 1. **Otomatisasi SSL/TLS via acme.sh**

Penerbitan sertifikat TLS otomatis memakai **acme.sh** (bukan Certbot):

| Aspek | acme.sh (v4.7) | Certbot |
|---|---|---|
| Ukuran | ~300 KB shell script | ~50 MB + Python stack |
| Dependensi | `curl` + `openssl` + `cron` + `socat` | Python 3 + pip + banyak modul |
| RAM | < 10 MB saat issuance | 50–100 MB |
| Auto-renew | Built-in cron (`--install-cronjob`) | Butuh systemd timer terpisah |
| DNS API | 150+ provider (termasuk Cloudflare) | Plugin per provider |

File baru:

- **`lib/ssl.sh`** — modul library (install, issue, install-cert, renew, status, remove)
- **`setup-ssl.sh`** — wrapper CLI (`--domain`, `--mode`, `--email`, `--status`, `--renew`, `--force`)
- **Menu 24** — `Setup SSL Certificate via acme.sh (standalone/DNS)`

### 2. **Dua Mode Issuance**

**Standalone (port 80 sementara)**:
- Validasi HTTP-01 Let's Encrypt via port 80
- Installer otomatis menghentikan service penghuni `:80` (`ssh-ws`, `nginx`, `apache2`, `caddy`) lalu **mengembalikannya** setelah issuance
- Port 80 dibuka via firewall dinamis v4.6
- Syarat: DNS A record domain → IP server ini + port 80 reachable dari internet

**DNS API Cloudflare (tahan CDN/firewall)**:
- Validasi DNS-01 — **tanpa buka port sama sekali**
- Handal di balik Cloudflare proxy (orange cloud), NAT, atau firewall ketat
- Kredensial via env (disarankan scoped token):
  ```bash
  export CF_Token='your-api-token'          # disarankan (izin Zone:DNS:Edit)
  # atau legacy:
  export CF_Key='global-key' CF_Email='you@example.com'
  ```
- Bisa menerbitkan sertifikat untuk domain yang bahkan tidak mengarah ke server ini

### 3. **Auto-Renew via Cron (Anti-Kedaluwarsa 90 Hari)**

- `$ACME_BIN --install-cronjob` — cron harian bawaan acme.sh
- Renew otomatis bila sisa < 30 hari (default Let's Encrypt 90 hari)
- `--reloadcmd "systemctl reload-or-restart xray"` — Xray otomatis reload setelah renew
- Status cron terlihat di `status.sh` dan `./setup-ssl.sh --status`

### 4. **Lokasi & Format Sertifikat Standar**

```
/etc/vpn-ssl/
├── params                  # domain, mode, email, dns provider (600)
└── <domain>/
    ├── fullchain.pem       # (644) untuk Xray / Nginx / Web Dashboard
    └── key.pem             # (600, root:root) private key
```

Siap dipakai untuk: Xray TLS inbounds, Stunnel, Nginx/Caddy reverse proxy, Web Dashboard (https).

### 5. **Pre-Install Default di `install.sh` (v4.7 revisi)**

acme.sh **terinstal otomatis saat instalasi awal** — user tidak perlu apa-apa untuk mulai pakai SSL:

- Step baru **15c** di `install.sh`: `ssl_install_acme --soft` setelah monitor limits
- **Soft mode**: bila download gagal (offline/blocked), instalasi VPN tetap lanjut + warning (tidak fatal)
- Idempotent: bila acme.sh sudah ada, langsung skip
- Kontrol: `--with-ssl` (default ON) / `--no-ssl` + prompt interaktif (default Y)
- Setelah instalasi, sertifikat tinggal diterbitkan: Menu 24 / `./setup-ssl.sh --domain ...`

### 6. **Integrasi Penuh**

- **`status.sh`** — seksi `SSL CERTIFICATE (acme.sh)`: domain, mode, VALID/EXPIRED + tanggal expiry, status cron
- **`uninstall.sh`** — `ssl_remove`: hapus sertifikat dari acme.sh + direktori domain
- **`menu.sh`** — footer version v4.6 → v4.7

## 📦 Cara Pakai

```bash
# Interaktif (tanya domain + mode)
sudo ./menu.sh          # pilih 24
# atau
sudo ./setup-ssl.sh

# Non-interaktif: standalone
sudo ./setup-ssl.sh --domain vpn.example.com --mode standalone --email you@example.com

# Non-interaktif: DNS API Cloudflare (di balik CDN/firewall)
export CF_Token='your-api-token'
sudo -E ./setup-ssl.sh --domain vpn.example.com --mode dns

# Cek status & renew manual
sudo ./setup-ssl.sh --status
sudo ./setup-ssl.sh --renew            # renew bila < 30 hari
sudo ./setup-ssl.sh --renew --force    # paksa renew
sudo ./status.sh                       # bagian SSL CERTIFICATE
```
