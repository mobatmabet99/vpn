## 🎉 Fitur Baru v4.6

### 1. **Dynamic Firewall Backend Detection**

Installer kini otomatis mendeteksi backend packet-filtering yang aktif dan hanya menambah aturan bila filtering benar-benar ditegakkan:

- **UFW** (aktif) → `ufw allow <port>/<proto>` + `DEFAULT_FORWARD_POLICY=ACCEPT`
- **firewalld** (aktif) → tambah port + `masquerade` di default zone (bukan hardcode `public`)
- **iptables** → aturan ACCEPT hanya bila `INPUT` policy DROP/REJECT atau sudah ada aturan filter
- **nftables** (native) → aturan di chain `inet filter input` yang sudah ada (tidak pernah membuat table/chain baru)
- **Tidak ada filtering** (VPS default semua ACCEPT) → tidak ada aturan yang ditambahkan, port sudah reachable

Fungsi baru di `lib/system.sh`:

| Fungsi | Tugas |
|---|---|
| `fw_detect_backend()` | Deteksi backend terbaik: `ufw` → `firewalld` → `iptables` → `nft` → `none` (hasil di-cache) |
| `fw_is_filtering_active()` | Cek apakah filtering benar-benar enforced |
| `open_firewall_port()` | Buka 1 port (kompatibel mundur, tambah argumen label opsional) |
| `open_firewall_ports()` | Buka banyak port sekaligus dengan 1 banner + 1 reload (batch) |
| `close_firewall_port()` | Hapus aturan (UFW + firewalld + iptables/nft, hapus duplikat) |
| `close_firewall_ports()` | Hapus banyak port sekaligus |
| `fw_status_summary()` | Ringkasan backend + status filtering untuk `status.sh` |

### 2. **Idempotent Rules (Tanpa Duplikat)**

- `iptables -C ... || iptables -I ...` sebelum menambah (IPv4 + IPv6 bila `ip6tables` ada)
- nft dicek dulu sebelum `add rule`; penghapusan memakai handle (hapus semua duplikat)
- `ufw --force delete` agar `close_firewall_port` tidak hang menunggu input interaktif

### 3. **Batch Open/Close (Log Rapi + 1 Reload)**

- Setup Xray (10 port) kini 1 banner + 1 reload, bukan 10 banner + 10 reload
- `uninstall.sh` menutup port SSH (22/143/444/8080) dan seluruh port Xray sekaligus
- Label aturan firewall per layanan (`WireGuard`, `SSH`, `Xray`, `OpenVPN`, `Shadowsocks`, `Web-Dashboard`)

### 4. **Bug Fix**

- `close_firewall_port` sekarang benar-benar menghapus aturan iptables/nft (sebelumnya hanya UFW + firewalld, aturan iptables tidak pernah dibersihkan)
- `uninstall.sh`: default `WS_PORT` diperbaiki `80` → `8080` (sesuai v4.2), plus menutup SSH port 22
- `uninstall.sh`: menutup seluruh port Xray v4 (10005–10008 + 80), sebelumnya hanya 10001–10004 + 443
- `setup-web-dashboard.sh`: tambah `source lib/system.sh` (sebelumnya memanggil `open_firewall_port` tanpa import → error `command not found`)
- `status.sh`: tambah `source lib/system.sh` + tampilkan backend firewall dinamis
- firewalld memakai default zone (`firewall-cmd --get-default-zone`), bukan hardcode `public`

## 🔧 Perubahan Teknis

### File yang Dimodifikasi

1. **`lib/system.sh`**:
   - Section firewall di-rewrite total (fungsi `fw_*` + batch helpers)

2. **`lib/xray.sh`**:
   - Loop 10× `open_firewall_port` → 1× `open_firewall_ports "Xray" "tcp" ...`

3. **`lib/ssh.sh`**:
   - Label firewall per layanan (`SSH`, `SSH-Dropbear`, `SSH-TLS`, `SSH-WS`)

4. **`lib/shadowsocks.sh`**, **`lib/openvpn.sh`**, **`install.sh`**:
   - Label firewall (`Shadowsocks`, `OpenVPN`, `WireGuard`, `Web-Dashboard`)

5. **`uninstall.sh`**:
   - Batch close untuk SSH + Xray, perbaiki default port WS

6. **`status.sh`**:
   - Tampilkan `Firewall backend` + `Packet filtering` status dinamis

7. **`menu.sh`**:
   - Footer version: v4.1 → v4.6

8. **`README.md` / `README.en.md` / `README.zh.md`**:
   - Dokumentasi firewall dinamis (UFW / firewalld / nftables / iptables)

### Kompatibilitas

- Semua pemanggil lama `open_firewall_port <port> <proto>` tetap bekerja (argumen label opsional)
- Tidak ada perubahan perilaku untuk UFW/firewalld yang aktif
- Perilaku baru hanya untuk host tanpa filtering (skip aturan) dan host nftables murni (aturan native)
