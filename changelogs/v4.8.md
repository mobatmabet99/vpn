## 🎉 Fitur Baru v4.8

### 1. **Strict Mode Terkonfirmasi (Audit Penuh)**

Audit seluruh 19 entry script + 10 library:

- ✅ Semua entry script sudah `set -euo pipefail` (berhenti saat error, var tak terdefinisi = fatal, pipeline gagal = fatal)
- ✅ Semua library punya guard `BASH_SOURCE` (tidak bisa dieksekusi langsung)
- ✅ Pola `|| die "..."` dipakai di titik kritis (download gagal, binary hilang, config korup)
- ✅ `curl -fsSL` di semua download + **`--retry 2 --connect-timeout`** (15–20 dtk) agar tidak hang di VPS dengan jaringan buruk

### 2. **Pengecekan Port Bentrok (Semua Layanan)**

Fungsi baru di `lib/common.sh`:

| Fungsi | Tugas |
|---|---|
| `is_port_in_use()` (diperkuat) | `ss` → `netstat` → `/proc/net/{tcp,tcp6,udp,udp6}` fallback; regex diperketat (`:port` + spasi/EOL, tidak lagi false-positive `:1000` vs `:10001`) |
| `port_owner()` | Tampilkan pemilik port (`ss -p` → `lsof` → `netstat`), mis. `"nginx"` atau `pid(1234)` |
| `check_port_free(port, proto, label, [--soft])` | Peringatan + pemilik + petunjuk `ss -lntp`; mode interaktif tanya lanjut/batal, mode `--soft`/`--yes` hanya warning |

Cakupan (semua `--soft`, tidak pernah menggagalkan instalasi):

- **SSH**: 22, 143 (Dropbear), 444 (Stunnel), 8080 (WS)
- **Xray**: 10001–10008 (WS + gRPC), 80 (XHTTP), 443 (REALITY)
- **OpenVPN**: 1194/udp (atau custom), **Shadowsocks**: port custom TCP+UDP
- **Web Dashboard**: port custom (default 3000)
- **SSL standalone :80**: pesan owner diperjelas sebelum stop-service otomatis
- WireGuard tetap memakai cek existing (interaktif, lebih ketat karena port inti)

### 3. **Clean-up Otomatis via Trap (Anti File Sampah)**

Infrastruktur baru di `lib/common.sh`:

- `track_temp <path>` — daftarkan file/dir sementara
- `install_cleanup_trap` — pasang trap `EXIT INT TERM` (sekali saja, idempotent)
- `vpn_cleanup_tracked` — hapus semua path terdaftar (`rm -rf`, best-effort)

Terpasang di:

- **13 entry script** (`install.sh`, `setup-*.sh`, `add/remove-*`, `uninstall.sh`) — gagal/Ctrl+C kapan pun → temp bersih
- **Semua temp**: Xray `.zip` + extract dir + JSON tmp, Shadowsocks `.tar.xz`, acme.sh installer, WireGuard tmp, 11 tmp di `limits.sh`

Jika instalasi gagal di tengah jalan (download putus, Ctrl+C, OOM), tidak ada lagi `/tmp/tmp.XXXX` atau `get-acme.sh` yang tertinggal.

## 📦 Cara Verifikasi di VPS

```bash
# Simulasi port bentrok (jalankan nginx dulu, lalu install — harus ada warning + owner)
sudo apt install -y nginx && sudo systemctl start nginx
sudo ./install.sh --yes   # warning port 80 untuk XHTTP + owner "nginx"

# Simulasi gagal tengah jalan — tidak ada temp sisa
ls /tmp/tmp.* /tmp/get-acme.sh 2>/dev/null  # harus kosong setelah Ctrl+C saat download

# Re-run aman (idempotent)
sudo ./install.sh --yes
```
